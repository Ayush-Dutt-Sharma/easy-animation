# Retro

Status: draft · Updated: 2026-09-27

Run this after every video, before the next one starts. Copy it to `videos/<name>/retro.md` and fill it in. This is the step that makes the library better.

## 1. Numbers

- The final length, and the number of shots and sets.
- Claude usage (5-hour windows and weekly %) and its API-equivalent cost. Update [COSTS.md](../../COSTS.md).
- Render speed: milliseconds per frame, and the full render time.
- Voice: credits used and the number of takes.

## 2. What worked

Keep doing it. If it's a new pattern, add it to [storytelling.md](../craft/storytelling.md) or [metaphors.md](../craft/metaphors.md).

## 3. What went wrong

Add each failure to [common-failures.md](../craft/common-failures.md), with a check that would have caught it and "Seen in: <video>".

## 4. Rules we broke

Which rule, why, and whether the rule should change. Change it only with evidence, and log the change.

## 5. Guesses replaced by measurements

Every starting number that turned out wrong (read times, levels, squash amounts, pace), and the module it lives in.

## 6. New pieces

List everything built for this video. For each piece, decide:
- promote it to the library now, because it's generic;
- promote it later, on second use;
- or keep it here, because it's a one-off.

Promoted pieces get generic names.

## 7. Status

Modules used in the finished video move to `proven`.

## 8. Changelog

Add one entry to [CHANGELOG.md](../CHANGELOG.md) listing the edits above.
